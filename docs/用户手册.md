# EVE 辅助工具 · 用户手册

> **适用版本**：v0.3.0　|　**支持服务器**：欧服（宁静，Tranquility）/ 国服经典服（晨曦，Serenity）/ 国服曙光服（Shuguang）
> **许可证**：GNU General Public License v3.0　|　**运行环境**：Node.js 18+
>
> 本手册面向**最终使用者**，按「装好 → 选服 → 授权 → 算账」的顺序写。
> 启动器命令、授权排错、公式出处等深入内容见 [本地使用说明](./本地使用说明.md) 与 [计算公式参考](./计算公式参考.md)。
> **术语口径**：技能与游戏名词采用「国服中文（欧服宁静英文）」双版本，完整对照见 [术语对照表](./术语对照表.md)。

---

## 1. 它能帮你做什么

这是一个**跑在你自己电脑上**的小工具，不依赖任何网站账号：

- 授权后把你的**真实技能（Skill）等级**拉下来，自动代入工业公式，不再手填
- 查**实时买卖单（Market Order）**和**历史成交（Market History）**，给蓝图（Blueprint）自动填材料单价
- 算**制造（Manufacturing）成本、利润、回报率、保本价、日产能**
- 按**服务器和挂单空间站（Station）**精确计算销售税（Sales Tax）与中介费（Broker Fee）（含声望修正）
- 查**矿石（Ore）精炼产出（Reprocessing Yield）**、星系成本指数（System Cost Index）、设施（Facility）分布

所有角色数据只存在本机，工具不会把它们上传到别处。

## 2. 开始之前

| 需要 | 说明 |
| --- | --- |
| Node.js 18 或更高 | 到 <https://nodejs.org> 下载 LTS 版安装；在终端输入 `node -v` 能显示版本号即可 |
| 一个现代浏览器 | Chrome / Edge 推荐 |
| （可选）EVE 应用的 Client ID | 想自动同步技能就需要；**每个服务器单独注册一个**。没有也能用「手动授权」或纯手动填技能 |

**不需要**：`npm install`（零第三方依赖）、数据库、云服务器、账号注册。

> 从 GitHub 下载源码时请把整个仓库一起下载（`git clone` 或 Download ZIP）。
> `data/sde/` 里的 16 张数据表是运行必需的，缺了页面会显示「未加载」。

## 3. 安装与启动

### Windows

双击项目根目录的 **`EVE辅助工具.cmd`**，会打开一个交互菜单：

```
1. 启动服务（前台，Ctrl+C 停止）
2. 启动服务（后台，终端可关）
3. 停止服务
4. 重启服务（后台模式）
5. 查看状态
6. 打开界面
7. 查看最近日志
8. 运行自检测试
0. 退出
```

选 `1` 即可。启动成功后浏览器会自动打开。

### macOS / Linux / WSL

```bash
chmod +x EVE辅助工具.sh
./EVE辅助工具.sh
```

### 手动启动（任意平台）

```bash
node server.js          # 然后浏览器打开 http://localhost:8657
```

### 常用命令

```bash
node scripts/launch.js bg                     # 后台启动
node scripts/launch.js status                 # 看运行状态与实际端口
node scripts/launch.js stop                   # 停止所有实例
node scripts/launch.js test                   # 跑离线自检（682 项）
node scripts/launch.js start --port 8660      # 换端口启动
node scripts/launch.js start --no-browser     # 不自动开浏览器
```

**默认地址**：<http://localhost:8657>。若端口被占用会自动顺延到 8658、8659……最多 +20；
实际端口写在 `用户数据/server.port`，用 `status` 命令也能查到。

## 4. 界面一览

```
┌──────────────────────────────────────────────────────────┐
│  EVE 辅助工具   [角色][市场][工业][制造][挂单][提炼][设置]   │
│                       [晨曦][曙光][欧服]  ← 顶部服务器切换 │
├──────────────────────────────────────────────────────────┤
│                      当前功能页内容                        │
└──────────────────────────────────────────────────────────┘
```

顶部栏左侧是品牌名，中间是七个功能页导航，右侧是三服切换按钮与当前授权状态。
**先选对服务器，再做任何核算**——三服的税率、类型 ID（typeID）体系、市场数据都不同。

## 5. 第一步：选服务器

点击顶部的 **晨曦 / 曙光 / 欧服** 按钮：

- 高亮立即跟随点击，并弹出切换提示
- 所选服会被记住，**刷新页面后仍停在该服**
- 切换时会清空上一服的行情与核算缓存，并重绘当前页
- 角色档案按服隔离：切到有档案的服会自动恢复角色；切到没有档案的服会清空当前角色
  （档案**没有删除**，切回来就恢复）

三服基础税率：

| 服务器 | 销售税基础（Sales Tax） | 中介费基础（Broker Fee） |
| --- | ---: | ---: |
| 欧服（宁静，Tranquility） | 7.5% | 3% |
| 国服经典服（晨曦，Serenity） | 8% | 2.5% |
| 国服曙光服（Shuguang） | 8% | 2.5% |

> 国服 8% 基础值与国服 wiki「会计学（Accounting）5 级后销售税约 3.6%」吻合（8% × 0.45 = 3.6%）。

## 6. 第二步：授权角色（可选但推荐）

不授权也能用全部核算页，只是技能按 0 级算；手填技能等级可做临时推演（**刷新后恢复**）。

### 方式 A · 标准授权

1. 在对应开发者后台注册应用，回调地址填 `http://localhost:8657/sso/callback`
   （端口若顺延过，按 `status` 显示的实际端口填）
2. 「设置」页填入该服的 **Client ID**
3. 「角色」页点该服的授权按钮 → 跳转到官方登录 → 同意后自动回到工具
4. 技能、属性、钱包、资产自动同步，之后可随时手动刷新

> 欧服走 CCP 开发者后台，国服走网易开发者后台；**曙光是独立集群，不能与晨曦共用应用**。

### 方式 B · 手动授权

不想注册应用时，用「角色」页的**手动授权**通道：按页面提示在浏览器完成官方登录，
把回调地址粘贴回工具即可。详细步骤见 [本地使用说明 · 方式二](./本地使用说明.md)。

### 授权失败怎么办

| 现象 | 排查 |
| --- | --- |
| 跳转后提示回调地址不匹配 | 回调地址必须与实际监听端口完全一致，含 `http://` 与末尾路径 |
| 授权后技能全是 0 级 | 检查是否选对了服务器；换服后需要重新授权该服角色 |
| 国服拉不到数据 | 用系统 Chrome/Edge，不要用内置浏览器；清理网易相关 Cookie 后重试 |
| 提示令牌过期 | 在「角色」页重新授权；已保存的角色档案仍可离线查看 |

更多排错见 [本地使用说明 · 授权失败排查](./本地使用说明.md)。

## 7. 功能页操作指南

### 角色

查看当前角色的技能、属性、钱包与资产。授权后自动同步；未授权时可**手动改技能等级**做推演。
页面顶部显示当前生效的服务器与授权状态；点某服的授权按钮时，顶部选服会**自动对齐**到该服。

### 市场

输入物品中文名 → 点「查询」：

- **实时买卖单**：左侧卖单升序、右侧买单降序，含单价、剩余量、地点
- **历史成交**：最近约 398 天的每日均价 / 最低 / 最高 / 成交量
- **★ 收藏**：把常查的物品加入收藏，之后一键查询

### 工业

查看当前星系（Solar System）的**成本指数（System Cost Index）**（制造 Manufacturing、时间效率研究 TE、材料效率研究 ME、蓝图拷贝 Blueprint Copying、发明 Invention、反应 Reaction）与设施（Facility）数量。

> **制造费口径**：工业费（Industry Job Cost）按「产物估算价值（Estimated Item Value, EIV）× 星系成本指数」计入，再叠加设施基础费与设施税（Facility Tax），
> **不是**按材料实际成本算。换星系会明显改变结果。

### 制造（蓝图画廊）

1. 搜**产物名**（如 `矮脚鸡级`）或**类别词**（如 `护卫舰`、`炮塔`）
2. 点目标蓝图（Blueprint）的「核算」
3. 填 **ME（材料效率研究）**、**TE（时间效率研究）**、**流程数（Runs）**、**工业费（Industry Job Cost）**
4. 点「**拉取材料价**」自动填单价（优先本地 EIV 基准价，缺失时回退查卖单最低价）
5. 填**产物卖价** → 自动出成本、利润、回报率、毛利率、保本价

要点：ME 每级减 1% 材料量并向上取整；保本价 = 单件成本 ÷ (1 − 销售税 − 中介费)；
**回报率 = 利润 ÷ 成本**，**毛利率 = 利润 ÷ 毛收入**，两者都显示，别混淆。

### 挂单

不依赖蓝图的快速核算器：填**单件成本、数量、目标回报率、单流程耗时、卖价**，
直接得到达到目标回报率/毛利率的最低卖价、保本价、净利润、日产能。
日产能按 `86400 ÷ 单流程耗时 × 槽位` 计算，槽位取自你的技能。

### 提炼

选择矿石（Ore）族（35 个）与级别，查看精炼产出（Reprocessing Yield）与数量。产出已计入
「提炼学概论（Reprocessing）+3%/级」与「提炼效率理论（Reprocessing Efficiency）+2%/级」的技能加成。

### 设置

- 各服 Client ID 与回调地址
- **税率与声望（挂单相关）**：见下一节
- 数据表状态、基础税率校准

## 8. 税率与声望（挂单必看）

工具用的是官方完整公式：

```
销售税（Sales Tax） = 基础 × (1 − 0.11 × 会计学等级)
中介费（Broker Fee） = 基础 − 0.3% × 经纪人关系学等级
                             − 0.03% × 势力声望 − 0.02% × 军团声望     （下限 1%）
```

公式中的技能：会计学（Accounting）、经纪人关系学（Broker Relations）。
**两项声望（Standings）都相对于「你挂单所在空间站（Station）的站主（Station Owner）」**：

| 项 | 查哪一项 | 每点减免 | 满 10 点 |
| --- | --- | --- | --- |
| 势力声望（Faction Standings） | 与**站主所属势力（Faction）**的声望 | −0.03% | −0.3% |
| 军团声望（Corporation Standings） | 与**站主军团（Corporation）**的声望 | −0.02% | −0.2% |

操作步骤：

1. 「设置」页 → 「税率与声望（挂单相关）」→ **搜索并选择挂单空间站（Station）**
   （新增站若搜不到，可直接**手填站名**，工具会按站名解析站主）
2. 工具自动识别**站主（Station Owner）**及**所属势力（Faction）**，并提示该查哪项声望
3. 填入游戏内「角色（Character）→ 声望（Standings）」里的**原始值**（不含外交 / 关系学加成）
4. 页面实时显示最终的销售税率与中介费率

注意：

- **负声望会提高费率**
- **玩家自建空间站（Player-Owned Structure）**的费率由业主设定，技能与声望都不适用
- 若游戏内读数与工具不一致，「设置」页底部有**基础税率校准**，直接填你看到的百分数即可，
  工具会立即按新值计算并存到本地

## 9. 数据、备份与隐私

所有个人数据都在项目根目录的 `用户数据/` 下，**不会随仓库提交**：

| 文件 / 目录 | 内容 |
| --- | --- |
| `eve_char_profiles_v1.json` | 角色档案（按服隔离） |
| `eve_config_v1.json` | Client ID、挂单空间站、声望、税率校准等设置 |
| `users/` | 多用户模式下各账号的数据与加密令牌 |
| `server_salt.txt` | 服务端盐；**迁移机器时必须一并保留**，否则已有会话会全部失效 |
| `logs/` | 后台运行日志 |
| `server.port` / `server.pid` | 运行期端口与进程记录 |

**备份**：停止服务后，直接复制整个 `用户数据/` 目录即可。
**重置**：删除 `用户数据/` 后重启，等于恢复出厂设置（角色档案会丢失，先备份）。

令牌在启用多用户模式时以 **AES-256-GCM** 加密落盘；公开市场数据按需从官方 ESI 拉取并本地缓存。

## 10. 常见问题

**Q：双击脚本没反应 / 提示找不到 Node？**
A：确认 `node -v` 有输出且 ≥18。Windows 上也可在项目目录开终端执行 `node scripts/launch.js start` 看报错。

**Q：页面显示旧内容、改了设置没生效？**
A：刷新页面（Ctrl+F5 强制刷新）。工具对静态资源带了文件版本号，一般不会出现缓存问题；
若仍异常，用 `status` 确认连的是当前代码启动的实例，必要时 `restart`。

**Q：搜「护卫舰」搜不到具体船名？**
A：输入类别词会返回该类别下所有可制造物品（内置了物品类别映射表）。

**Q：拉取材料价很慢 / 提示取不到价格？**
A：正常走本地 EIV 缓存是秒级；个别物品没有 EIV 会回退逐个查订单。先检查网络，
国服 ESI 若受内置浏览器 Cookie 干扰，改用系统 Chrome/Edge。

**Q：手动改了技能，刷新后又变回去了？**
A：正常。手动改写只是临时推演，刷新后回到角色实际技能。

**Q：数据表显示「未加载」？**
A：正常 —— 只有用到该表的页面才会加载它。若整页都取不到，检查 `data/sde/` 是否完整。

**Q：怎么确认我装的是完整可运行的版本？**
A：执行 `npm test`，应显示 **10 个测试文件、682 项全部通过**。

## 11. 停止、重置与卸载

```bash
node scripts/launch.js stop      # 停止所有运行中的实例
```

前台启动时直接按 `Ctrl+C` 也会停止。

- **重置设置**：删除 `用户数据/eve_config_v1.json`（先备份）
- **卸载**：停止服务后删除整个项目文件夹即可；工具不写注册表、不装系统服务
