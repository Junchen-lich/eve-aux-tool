# 计算公式参考

> 每个公式的官方出处与精确数值。实现见 `src/core/skills.js`，自检见 `src/core/skills.test.js`。
>
> **术语口径**：英文名称采用欧服宁静（Tranquility）官方名称，中文名称采用国服（晨曦 / 曙光）译名；
> 完整对照见 [术语对照表](./术语对照表.md)。公式代码块内使用中文简称，紧邻表格给出双语对照。

## 一、税率

### 1.1 三服基准税率

三套集群的销售税（Sales Tax）与中介费（Broker Fee）基准值不同，计算前须按服务器取值。

| 服务器 | 销售税基础（Sales Tax） | 中介费基础（Broker Fee） |
| --- | ---: | ---: |
| 欧服（宁静，Tranquility） | 7.5% | 3% |
| 国服经典服（晨曦，Serenity） | 8% | 2.5% |
| 国服曙光服（Shuguang） | 8% | 2.5% |

基准值存放于 `data/sde/tax_config.json`，可在「设置」页按游戏内读数校准。

### 1.2 销售税（Sales Tax）

```
销售税 = 基础 × (1 − 0.11 × 会计学等级)
```

| 会计学（Accounting）等级 | 欧服（基础 7.5%） | 国服（基础 8%） |
| --- | ---: | ---: |
| 0 | 7.50% | 8.00% |
| 1 | 6.675% | 7.12% |
| 2 | 5.85% | 6.24% |
| 3 | 5.025% | 5.36% |
| 4 | 4.20% | 4.48% |
| 5 | **3.375%** | **3.60%** |

- 出处：CCP 支持中心《Broker Fees and Sales Tax》
- 欧服基础值自版本 22.02（2025-03-12）起为 **7.5%**；国服基础值为 **8%**
- 收取方式：卖出成交时由系统从售价扣除，记入钱包「Transaction Tax（交易税）」

### 1.3 中介费（Broker Fee）

```
中介费 = 基础 − 0.3% × 经纪人关系学等级
              − 0.03% × 势力声望
              − 0.02% × 军团声望                    （下限 1%）
```

| 经纪人关系学（Broker Relations）等级 | 欧服（基础 3%） | 国服（基础 2.5%） |
| --- | ---: | ---: |
| 0 | 3.00% | 2.50% |
| 1 | 2.70% | 2.20% |
| 2 | 2.40% | 1.90% |
| 3 | 2.10% | 1.60% |
| 4 | 1.80% | 1.30% |
| 5 | **1.50%** | **1.00%** |

- 出处：CCP 支持中心 + EVEU Wiki《Tax》
- 两项声望均相对于**挂单所在空间站（Station）的站主（Station Owner）**：
  势力声望（Faction Standings）查站主所属势力，军团声望（Corporation Standings）查站主军团
- 声望只取**原始值**（不含外交、关系学等技能加成）；负声望会提高费率
- 收取方式：**挂单时**按市场订单（Market Order）总额收取，撤单不退
- **玩家建筑（Upwell Structure）例外**：费率由建筑所有者设定，技能与声望均不适用

## 二、制造与研究时间

```
制造时间系数 = (1 − 0.04 × 工业理论) × (1 − 0.03 × 高级工业理论)
```

| 组合 | 系数 |
| --- | ---: |
| 无技能 | 100% |
| 工业理论（Industry）V | 80% |
| 高级工业理论（Advanced Industry）V | 85% |
| 双 V | **68%** |

- 工业理论（Industry）：每级制造（Manufacturing）时间 −4%（CCP DevBlog / EVE 中文维基《技能/生产》）
- 高级工业理论（Advanced Industry）：每级全部制造与研究时间 −3%
- 下限保护：系数不低于 20%

### 2.1 研究速度系数

| 研究类型 | 工业活动 ID（activityID） | 受影响技能 | 公式 |
| --- | ---: | --- | --- |
| 材料效率研究（Material Efficiency Research, ME） | 4 | 科学原理（Science）+ 冶金学（Metallurgy） | `(1−0.05×sci)(1−0.05×metal)` |
| 时间效率研究（Time Efficiency Research, TE） | 3 | 研究概论（Research） | `1−0.05×res` |
| 蓝图拷贝（Blueprint Copying） | 5 | 科学原理（Science） | `1−0.05×sci` |
| 发明（Invention） | 8 | 科学原理（Science） | `1−0.05×sci` |

工业活动 ID 对照：制造（Manufacturing）1、时间效率研究 3、材料效率研究 4、蓝图拷贝 5、发明 8、反应（Reaction）11。
反应（Reaction）的数据位于 SDE `industryActivity` 的 act=11。

### 2.2 同时槽位

```
制造槽（Manufacturing Slot） = 1 + 批量生产学 + 高级量产技术
研究槽（Research Slot）     = 1 + 实验室运作理论 + 高级实验室运作理论
```

- 批量生产学（Mass Production）、高级量产技术（Advanced Mass Production）各 +1 制造槽/级
- 实验室运作理论（Laboratory Operation）、高级实验室运作理论（Advanced Laboratory Operation）各 +1 研究槽/级

批量生产学 V + 高级量产技术 IV → 10 条产线。

## 三、材料效率（ME）与时间效率（TE）

### 3.1 材料效率减材

```
材料减少系数 = 1 − ME 等级 × 1%
项目材料 = 蓝图（Blueprint）所需材料 × 减少系数 × 流程数（Runs）
```

**官方限制**：

1. ME 计算作用于**整个工业作业（Industry Job）**，不是每个 run
2. 结果**向上取整到下一位有效数字**（14.4 → 15）
3. 「每 run 需 1 个单位」的材料**不受 ME 影响**（造 10 艘帕拉丁级需 10 艘灾难级，与 ME 无关）

### 3.2 时间效率减时

```
时间系数 = 1 − TE 等级 × 2%
```

ME 最高 10 级（−10%），TE 最高 20 级（−40%）。研究每级耗时递增（收益递减）。

## 四、提炼与精炼产出

```
提炼产出加成 = 3% × 提炼学概论 + 2% × 提炼效率理论
```

- 提炼学概论（Reprocessing）、提炼效率理论（Reprocessing Efficiency）双五级 → **+25%**
- 国服中文沿用「提炼」译名，欧服宁静现名为 Reprocessing / Reprocessing Efficiency

配套数据：`ore_refine.json`（矿石族 × 级别 → 精炼产物）+ 矿物（Mineral）收购价（c3q `evemon` 行情接口）。

**炼化税**：基础 5%，按玩家/军团对空间站所有者的声望（Standings）可降至 0%（需 6.67 声望）。

## 五、制造成本

```
单流程成本 = 材料成本 + 工业费
单件成本   = 单流程成本 ÷ 单流程产出数
总成本     = 单流程成本 × 流程数
```

### 5.1 工业费口径

```
工业费（Industry Job Cost） = 估算价值（EIV） × (星系成本指数 + 设施税 + SCC 附加费 + 阿尔法克隆税)
```

**按「估算价值」而非材料实际成本计算**。星系成本指数（System Cost Index）高时，工业费按 EIV 基准价算，
可能远高于实际材料成本，界面须明示。

数据源：

- 星系成本指数（System Cost Index）：ESI `GET /industry/systems/`（5485 个星系，含 manufacturing / researching_time_efficiency / researching_material_efficiency 等活动分类）
- 设施与费率（Facility）：ESI `GET /industry/facilities/`（2321 条）
- 估算价值（Estimated Item Value, EIV）：ESI `GET /markets/prices/`（欧服 16064 条 / 国服 11834 条）

## 六、挂单收益

```
毛收入     = 卖价 × 数量
销售税     = 毛收入 × 销售税率
中介费     = 毛收入 × 中介费率（玩家建筑则用业主设定值）
净收入     = 毛收入 − 销售税 − 中介费
利润       = 净收入 − 单件成本 × 数量
投资回报率 = 利润 ÷ 成本        （行业惯例口径，主用）
毛利率     = 利润 ÷ 毛收入      （辅助口径）
保本卖价   = 单件成本 ÷ (1 − 销售税率 − 中介费率)
```

### 6.1 反解最低卖价

两种口径须明确区分：

```
目标投资回报率 m：P = 单件成本 × (1 + m) ÷ (1 − 税率合计)
目标毛利率     m：P = 单件成本 ÷ (1 − 税率合计 − m)
```

「利润率」在玩家间常混用两种口径，工具同时给出两个数并分别标注。

## 七、日产能

```
日流程数 = (86400 ÷ 单流程秒数) × 同时槽数
日产出数 = 日流程数 × 单流程产出数
日利润   = 日流程数 × 单流程利润
```

单流程秒数 = SDE 蓝图耗时 × 制造时间系数。

## 八、行星工业（Planetary Industry, PI）

```
NPC 进出口税（Import / Export Tax） = 10% × (1 − 0.10 × 海关操作专业理论等级)
```

- 海关操作专业理论（Customs Code Expertise）V → **5%**
- 玩家海关办公室（POCO）所有者可另加收税率，合计最高 100%
- 低安（Lowsec）/ 零安（Nullsec）/ 虫洞（Wormhole）不适用

数据源：SDE `planetSchematics`（69 配方）+ `planetSchematicsTypeMap`（204 项）。

## 十、需随游戏版本核对的常量

以下不属于 SDE（Static Data Export），须人工维护，存放于 `data/sde/skills_zh.json` 与 `data/sde/tax_config.json`：

- 技能的每级效果数值
- 三服税率基础值与每级减量
- 制造 / 研究时间每级百分比
- 提炼产出每级百分比
- 行星工业税率

**核对触发条件**：CCP 或网易版本公告提到工业 / 税率变更；用户反馈数值与游戏内显示不符。
