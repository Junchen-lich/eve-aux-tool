# 计算公式参考

> 每个公式的官方出处、精确数值、易错点。
> 实现见 `src/core/skills.js`，自检见 `src/core/skills.test.js`（38 项断言）。

---

## 一、税率

### 1.1 销售税（交易税）

```
销售税 = 7.5% − 0.55% × 会计学等级
```

| 会计学等级 | 销售税率 |
| --- | --- |
| 0 | 7.50% |
| 1 | 6.95% |
| 2 | 6.40% |
| 3 | 5.85% |
| 4 | 5.30% |
| 5 | **4.80%** |

- 出处：CCP 支持中心《Broker Fee and Sales Tax》
- ⚠️ **历史变更**：销售税基础值在 **版本 22.02（2025-03-12）** 从 4% 上调到 **7.5%**。EVEU Wiki 正文仍写「可降至 3.3%」（旧值），实际 5 级会计学为 3.37%…3.3% 是旧基础值下的结果，当前应为 4.80%。
- 收取方式：卖出时由系统自动从售价扣除，记入钱包「Transaction Tax」。

### 1.2 经纪费

```
经纪费 = 3% − 0.3% × 经纪人关系学等级 − 0.03% × 势力声望 − 0.02% × 公司声望
```

| 经纪人关系学等级 | 经纪费（无声望） |
| --- | --- |
| 0 | 3.00% |
| 1 | 2.70% |
| 2 | 2.40% |
| 3 | 2.10% |
| 4 | 1.80% |
| 5 | **1.50%** |

- 出处：CCP 支持中心 + EVEU Wiki《Tax》
- 最低 1%（需经纪人关系学 V + 满声望）
- 收取方式：**挂单时**按订单总额收取，撤单不退；由空间站所有者收取
- ⚠️ **玩家建筑例外**：Upwell 建筑的经纪费由建筑所有者设定，**技能与声望都不影响**
- ⚠️ 声望项只取**未受技能加成**的原始声望

### 1.3 ★ 与旧项目的算法差异

旧项目（市场动态与制造核算台）用的是 `1.5% × (1 − 0.11 × 等级)` 与 `1.5% × (1 − 0.05 × 等级)`。

**两处错误，性质不同**：
- **销售税**：系数 0.11 本身**正确**，错的是**基础值**（用了 1.5%，官方 7.5%）→ 各等级均低估 5 倍
- **经纪费**：官方是**减法** `3% − 0.3%×等级`，旧项目误用**乘法** `×(1−0.05×等级)` → 5 级时旧值 1.125% vs 官方 1.50%

| 会计学等级 | 旧项目 | 官方 | 偏差 |
| --- | --- | --- | --- |
| 0 | 1.50% | 7.50% | 低估 5.0× |
| 3 | 1.00% | 5.025% | 低估 5.0× |
| 5 | 0.67% | 3.375% | 低估 5.0× |

→ 旧项目算出的挂单收益**系统性偏高**。已于 2026-11-03 修正（提交 `cc9c435`）。

## 二、制造与研究时间

```
制造时间系数 = (1 − 0.04 × 工业理论) × (1 − 0.03 × 高级工业理论)
```

| 组合 | 系数 |
| --- | --- |
| 无技能 | 100% |
| 工业理论 V | 80% |
| 高级工业理论 V | 85% |
| 双 V | **68%** |

- 工业理论：每级制造时间 -4%（CCP DevBlog / EVE 中文维基《技能/生产》）
- 高级工业理论：每级**所有制造与研究**时间 -3%
- 下限保护：系数不低于 20%

### 2.1 研究速度系数

| 研究类型 | 活动 ID | 受影响技能 | 公式 |
| --- | --- | --- | --- |
| 材料效率研究（ME） | 4 | 科学原理 + 冶金学 | `(1−0.05×sci)(1−0.05×metal)` |
| 时间效率研究（TE） | 3 | 研究概论 | `1−0.05×res` |
| 拷贝 | 5 | 科学原理 | `1−0.05×sci` |
| 发明 | 8 | 科学原理 | `1−0.05×sci` |

> ⚠️ **活动 ID 是 11 不是 9**：反应（Reaction）的活动 ID 为 **11**。SDE `industryActivity` 中 act=11 覆盖 120 条，不存在 act=9。旧项目的两份文档均误写为 9。

### 2.2 同时槽位

```
制造槽 = 1 + 批量生产学 + 高级量产技术
研发槽 = 1 + 实验室运作理论
```

批量生产学 V + 高级量产技术 IV → 10 条产线。

## 三、材料效率（ME）与时间效率（TE）

### 3.1 ME 减材

```
材料减少系数 = 1 − ME等级 × 1%
项目材料 = 蓝图所需材料 × 减少系数 × 流程数
```

**官方限制（三条，易错）**：
1. ME 计算作用于**整个 job**，不是每个 run
2. 结果**向上取整到下一位有效数字**（14.4 → 15）
3. 「每 run 需 1 个单位」的材料**不受 ME 影响**（造 10 艘帕拉丁需 10 艘灾难级，与 ME 无关）

### 3.2 TE 减时

```
时间系数 = 1 − TE等级 × 2%
```

ME 最高 10 级（-10%），TE 最高 20 级（-40%）。研究每级耗时递增（收益递减）。

## 四、精炼与提炼

```
精炼产出加成 = 3% × 提炼学概论 + 2% × 提炼效率理论
```

双五级 → +25%。

配套数据：`ore_refine.json`（矿石族 × 级别 → 精炼产物）+ 矿物收购价（c3q `evemon` 或旧项目用的 ceve `/evemon`）。

**炼化税**：基础 5%，按玩家/公司对空间站所有者的声望可降至 0%（需 6.67 声望）。

## 五、制造成本

```
单流程成本 = 材料成本 + 工业费
单件成本   = 单流程成本 ÷ 单流程产出数
总成本     = 单流程成本 × 流程数
```

### 5.1 ★ 工业费口径

```
工业费 = 物品估算价值 × (星系成本指数 + 设施税 + SCC 附加费 + Alpha 克隆税)
```

⚠️ **按「估算价值」而非材料实际成本计算**。这与直觉不同：星系成本指数高时，工业费按 EIV 基准价算，可能远高于实际材料成本。UI 必须明示。

数据源：
- 星系成本指数：ESI `GET /industry/systems/`（5485 个星系，含 manufacturing / researching_time_efficiency / researching_material_efficiency 等活动分类）
- 设施与费率：ESI `GET /industry/facilities/`（2321 条）
- 估算价值：ESI `GET /markets/prices/`（EIV 调整后价格，欧服 16064 条 / 国服 11834 条）

## 六、挂单收益

```
毛收入     = 卖价 × 数量
销售税     = 毛收入 × 销售税率
经纪费     = 毛收入 × 经纪费率（玩家建筑则用业主设定值）
净收入     = 毛收入 − 销售税 − 经纪费
利润       = 净收入 − 单件成本 × 数量
投资回报率 = 利润 ÷ 成本        （行业惯例口径，主用）
毛利率     = 利润 ÷ 毛收入      （辅助口径）
保本卖价   = 单件成本 ÷ (1 − 销售税率 − 经纪费率)
```

### 6.1 反解最低卖价

两种口径，**必须明确区分**：

```
目标投资回报率 m：P = 单件成本 × (1 + m) ÷ (1 − 税率合计)
目标毛利率     m：P = 单件成本 ÷ (1 − 税率合计 − m)
```

> ⚠️ 「利润率」一词在玩家间常混用两种口径。工具应同时给出两个数并标注，避免用户以为算错。

## 七、日产能

```
日流程数 = (86400 ÷ 单流程秒数) × 同时槽数
日产出数 = 日流程数 × 单流程产出数
日利润   = 日流程数 × 单流程利润
```

单流程秒数 = SDE 蓝图耗时 × 制造时间系数。

## 八、行星工业

```
PI NPC 税 = 10% × (1 − 0.10 × 报关代码专家等级)
```

报关代码专家 V → 5%。POCO 所有者另可加收（合计最高 100%）。
低安/_nullsec/虫洞不适用。

## 十、需随游戏版本核对的常量

以下不属于 SDE，必须人工维护（存 `data/skills.json` 与 `data/tax_config.json`）：

- 11+ 项技能的每级效果数值
- 税率基础值与每级减量
- 制造/研究时间每级百分比
- 精炼产出每级百分比
- 行星工业税率

**核对触发条件**：CCP 版本更新公告提到工业/税率变更；用户反馈数值与游戏内显示不符。
