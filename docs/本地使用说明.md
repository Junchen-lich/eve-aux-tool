# EVE 辅助工具 —— 本地使用说明

> 面向个人日常使用：启动、授权、四个核算页面的用法与口径说明。

---

## 一、启动

### 一键脚本（推荐）

**Windows**：双击项目根目录的 `EVE辅助工具.cmd`
**macOS / Linux / WSL**：执行 `./EVE辅助工具.sh`

会进入交互菜单：

```
  1. 启动服务（前台，Ctrl+C 停止）
  2. 启动服务（后台，终端可关）
  3. 停止服务
  4. 重启服务（后台模式）
  5. 查看状态
  6. 打开界面
  7. 查看最近日志
  8. 运行自检测试
  0. 退出
```

也可以直接用命令（脚本等价于 `node scripts/launch.js <命令>`）：

| 命令 | 说明 |
| --- | --- |
| `EVE辅助工具.cmd start` | 前台启动，Ctrl+C 停止 |
| `EVE辅助工具.cmd bg` | 后台启动，终端可关，日志写入 `用户数据/logs/` |
| `EVE辅助工具.cmd stop` | 停止全部实例 |
| `EVE辅助工具.cmd restart` | 重启 |
| `EVE辅助工具.cmd status` | 查看状态 |
| `EVE辅助工具.cmd open` | 仅打开浏览器 |
| `EVE辅助工具.cmd logs` | 查看最近日志 |
| `EVE辅助工具.cmd test` | 运行离线自检 |

常用选项：`--port 8660`（指定起始端口）、`--multi-user`（启用多用户模式）、`--no-browser`（不自动开浏览器）。

### 脚本做了什么

- **自动探测空闲端口**：默认 8657，被占用时自动顺延（上限 +20）
- **健康检查确认就绪**：轮询 `/healthz` 确认真实端口后才拉起浏览器，避免打开无效地址
- **避免重复启动**：已在运行时直接打开浏览器，不再起第二个进程
- **多实例并行**：可同时开多个端口（`--port`），`status` 全部列出，`stop` 一次全停
- **孤儿实例回收**：记录文件丢失时按端口反查 PID（Windows `netstat` / Unix `lsof`）并停止
- **自动载入 `.env`**：存在时读取，但不覆盖已设置的环境变量

> `.cmd` 文件刻意保持纯 ASCII —— Windows 批处理处理 UTF-8 中文时会出现乱码与
> 文件指针错位。所有中文提示由 `scripts/launch.js` 输出。

### 手动启动

```bash
cd "E:/工作/搞个程序/EVE/EVE辅助工具"
node server.js
```

打开 <http://localhost:8657>。

- 默认**单用户模式**：不校验口令，数据存在 `用户数据/users/local/`
- 默认**只监听 127.0.0.1**：局域网与公网都访问不到（个人使用更安全）
- 端口被占用会自动 +1 回退（上限 +20）

停止：终端按 `Ctrl+C`（会优雅关闭，等在途请求完成）。

## 二、首次使用：授权角色

**这是本工具与旧项目最大的不同** —— 技能不用手填。

工具提供**两条并存的授权路径**，按你的情况任选其一：

| | 方式一 · 标准授权 | 方式二 · 手动授权 |
| --- | --- | --- |
| 需要什么 | 自己注册应用，拿到 Client ID | **什么都不用注册** |
| 流程 | 点按钮 → 浏览器授权 → 自动跳回工具 | 生成链接 → 浏览器授权 → **把地址栏地址粘回工具** |
| 回调地址 | `http://localhost:8657/sso/callback` | 网易官方落地页 |
| 令牌续期 | ✅ 有 refresh_token，自动刷新 | ❌ 无 refresh_token，约 20 分钟过期 |
| **数据保留** | ✅ 授权成功即落盘 | ✅ **同样落盘，不随令牌过期作废** |

> ★ **无论走哪条路，拉取到的角色数据（技能等）都会长期保留在本地**，
> 令牌过期只影响「能否再次拉取新数据」，不影响「已有的技能参数还能不能用来算账」。
> 令牌过期后重新授权一次即可继续同步。

### 左上角服务器切换（晨曦 / 曙光 / 欧服）

三个按钮决定**全部数据来源** —— 行情、星域、税率基准、角色档案都按选中的服取，
三服数据完全隔离，不会互相混用。

- 页面一打开就能点，不依赖后端配置接口；接口暂时失败时仍可用内置列表切换。
- 点击后高亮立即跟随，并提示「已切换到 XX」；设置页的服务器、市场星域、
  销售税率、经纪费率会同步刷新（欧服 7.5% / 3%，国服晨曦与曙光 8% / 2.5%）。
- 选择会保存在本机，刷新页面后仍停在上次选中的服。
- 切服会清空旧服行情缓存并**重绘当前页**；其他页在切换过去时按新服重新渲染。
- 角色档案按服隔离：切到有本地档案的服会自动恢复该服角色；没有档案时清空
  别服角色（数据仍保存在本地档案里，切回原服即恢复），避免拿别服技能算本服税率。
- 在「角色」页直接点某服的「授权 XX 服」按钮时，左上角会自动对齐到该服。

### 方式一 · 标准授权（推荐）

1. 在「设置」页为该服填入 Client ID 与回调地址
2. 顶部右侧选服务器（晨曦 / 曙光 / 欧服）
3. 「角色」页点对应的「授权 XX 服」按钮
4. 浏览器跳转 EVE 官方登录页，登录并同意授权
   - 只申请 `esi-skills.read_skills.v1`（读取角色技能）一项权限
   - **不会**访问你的资产、钱包、行业任务
5. 授权后自动回调本地，同步技能并进入「角色」页

### 方式二 · 手动授权（无需注册应用）

适合不想注册开发者应用的情况 —— 用网易官方公共 Client ID 授权。

1. 「角色」页点「生成授权链接…」
2. 选服务器、选授权方式 → 点「生成授权链接」
3. 点「在浏览器打开」（**若浏览器残留失效 Cookie，改点「用无痕窗口打开」**）
4. 在浏览器里登录网易账号并同意授权
5. 授权后浏览器会跳到 `ali-esi.evepc.163.com` 开头的地址 —— **整段复制**
6. 粘贴回工具的输入框，点「完成授权」
7. 工具自动换取令牌并立即同步技能到本地

#### 两种授权方式怎么选

| | 授权码流程 | 隐式流程 |
| --- | --- | --- |
| 地址栏形态 | `?code=…&state=…` | `#access_token=…` |
| 安全性 | ✅ PKCE 保护 | ⚠ 令牌直接出现在地址栏 |
| 有效期 | **只有几十秒**，粘慢了会失效 | 无此限制 |
| 换令牌 | 需要 state 配套 | 不需要 |

**建议**：先试授权码流程；反复失败（提示 HTTP 500）就换隐式流程 —— 它不依赖
`code_verifier` 配对，也没有过期限制。

> ★ **别把步骤 2 生成的「授权链接」粘进去** —— 它只是用来打开登录页的，
> 本身不含授权码。工具会识别出这种误粘贴并给出提示。

#### 打开后没跳转、只显示一段 JSON 报错？

```json
{"error":"invalid_request","error_description":"Unable to check RealID binding
 if user isn't logged in. Missing Netease token."}
```

这是**浏览器里残留了失效的网易 Cookie** —— 服务端把旧 Cookie 当成「已登录」，
继而做实名认证校验时失败，于是**不跳转、直接在 authorize 地址上返回这段 JSON**。

三种解法（任选其一）：

| | 做法 |
| --- | --- |
| A（推荐） | 点「**用无痕窗口打开**」—— 复制链接后，在无痕/隐私窗口里粘贴打开 |
| B | 清除 `login-infinity.evepc.163.com`（晨曦则 `login.evepc.163.com`）的 Cookie |
| C | 先正常打开登录页登录一次，再打开授权链接 |

> ⚠ 曙光服用**独立的登录集群** `login-infinity.evepc.163.com`，
> 需要用**曙光服的账号**登录（与晨曦服账号不通）。

#### 提示「网易拒绝了这次令牌交换（HTTP 500）」？

网易对**无效授权码**只会回一句无信息的 `An error has occurred.`。
实测确认（缺 `client_id` 才是 401，一旦带上 `client_id`，无论码是否有效都是 500），
最可能是：

| | 原因 | 处理 |
| --- | --- | --- |
| 1 | **授权码已过期**（最常见） | 重新生成链接，授权完**立刻**粘贴 |
| 2 | 授权码与生成它的链接不配套 | 必须用刚生成的那条链接去授权 |
| 3 | 授权码已被用过一次 | 别重复粘贴同一个地址 |
| 4 | state 不匹配 | 粘贴的地址要和「生成授权链接」那一次配套 |
| 5 | redirect_uri 不一致 | 手动通道固定用 `https://ali-esi.evepc.163.com/ui/oauth2-redirect.html` |

**反复失败就改用隐式流程**：「生成授权链接…」面板里有「授权方式」下拉框，
选「隐式流程」重新生成 —— 它不需要 `code_verifier`，也没有几十秒的过期限制。

#### ⚠ 授权成功了，但技能数据拿不到？

若看到「角色身份已识别，但**技能数据拿不到**（权限不足）」，
这是**网易官方公共 Client ID 的已知限制**，不是工具的 bug。

实测（2026-11-04，用真实令牌逐个端点验证）：

| 端点 | 结果 |
| --- | --- |
| `/characters/{id}`（角色名、生日、性别、种族、军团） | ✅ 200 |
| `/characters/{id}/skills`（技能） | ❌ 403 |
| `/characters/{id}/attributes`（属性） | ❌ 403 |
| `/characters/{id}/wallet`（钱包） | ❌ 403 |

**原因**：令牌 JWT 里的 `scp` 字段是**你请求的** scope，不是**实际授予的**。
网易后台给这个公共 ID 只配了极少数 scope，不含 `esi-skills.read_skills.v1`。

**两条出路**：

| | 做法 | 特点 |
| --- | --- | --- |
| 1 | **手动填写技能**（立刻可用） | 「角色」页 → 「手动填写技能…」，填 14 项等级；数据长期保留，但不会自动更新 |
| 2 | **自己注册应用**（一劳永逸） | 网易开发者后台注册并勾选「读取角色技能」，Client ID 填进「设置」页 |

> 不处理也能用 —— 工具会按 **0 级技能**计算（税率偏高、收益偏低，偏保守）。

### 技能显示与微调

「角色」页列出各项技能，每项显示：

| 项 | 含义 |
| --- | --- |
| 名称与效果 | 如「会计学 · 市场销售税每级 −11%」 |
| Lv 徽章 | 当前等级（Lv5 为蓝色高亮） |
| 输入框 | 可临时改写，用于「假设我升到 V 级会怎样」的推演 |
| 进度条 | 等级比例 |

**手动改写的技能会标注「已手动覆盖」**，**刷新页面即恢复为角色实际技能** —— 不会污染真实数据。

下方「当前生效参数」实时汇总：销售税、经纪费、制造时间系数、制造槽、实验室槽、精炼加成。**这些值会直接代入挂单收益与制造核算。**

### ★ 技能名与效果以国服游戏内为准

技能表在 `data/sde/skills_zh.json`，是**唯一来源**：

- **中文名**取自国服官方技能库（everef.net），与游戏内显示一致
- **效果描述**逐字取自国服 ESI `/universe/types/{type_id}` 的官方 `description`，未做二次改写
- **typeID** 全部在国服 ESI 实地验证过

几个容易混淆的点：

| 技能 | 作用对象 |
| --- | --- |
| 科学原理（Science, 3402） | 蓝图**拷贝**速度 +5%/级 |
| 研究概论（Research, 3403） | 蓝图**研究**（制造时间）−5%/级 |
| 冶金学（Metallurgy, 3409） | **材料效率（ME）研究**速度 +5%/级 |

三者常被混为一谈 —— 它们影响的是完全不同的环节。

> **三服税率不同**：国服（晨曦 / 曙光）销售税 8%、中介费 2.5%，
> 欧服（宁静）销售税 7.5%、中介费 3%。工具按左上角选中的服务器自动取值，
> 详见下文「四、税率口径（已按官方公式校正）」。

### ★ 各服的 Client ID 要分开注册

三套集群的应用**互不通用**，必须各注册一个：

| 服 | 在哪注册 | 授权端点 |
| --- | --- | --- |
| 欧服（宁静） | `developers.eveonline.com` | `login.eveonline.com` |
| 国服 晨曦 | 网易开发者后台 | `login.evepc.163.com` |
| 国服 曙光 | 网易开发者后台 | **`login-infinity.evepc.163.com`** |

> ★ **曙光服有独立的登录集群**（`login-infinity.evepc.163.com`），
> 与晨曦（`login.evepc.163.com`）是两个不同的账号体系，
> **曙光需单独注册应用，不能与晨曦共用 Client ID**。

在工具的「设置」页 → 「授权凭据（各服独立）」里分别填写。

> ⚠ **不要用网易官方公共 Client ID** `bc90aa496a404724a93f41b4f4e97761`
> 做**标准授权** —— 它在后台只登记了官方落地页，本地工具无法用它自动跳回。
> 但**可以**用它走上面的「方式二 · 手动授权」。

> ⚠ **回调地址必须逐字符一致** —— 协议、主机名、端口、路径、末尾斜杠都算差异。
> 网易把 `localhost` 和 `127.0.0.1` 当两个不同的值。
> 本工具本地默认上报 `http://localhost:8657/sso/callback`（端口被占用时会自动顺延，
> 上报的地址也会跟着变，启动日志里会打印实际值）。

### ★ 授权失败排查

工具现在会在**跳转登录前**做一次前置检查，能拦下必然失败的请求并直接说明原因。
如果仍遇到以下错误：

| 错误 | 原因 | 处理 |
| --- | --- | --- |
| `The redirect URL does not match any of the configured values for this client` | 回调地址与后台登记的不一致 | 逐字符核对；曙光需单独注册应用 |
| `Missing Netease token` | 浏览器残留失效网易 Cookie | 清 `login.evepc.163.com` 的 Cookie，或用无痕窗口 |
| `invalid_client` | Client ID 无效或用错服 | 确认是哪个服的应用 |
| `state 无效或已过期` | 授权码失效 | 重新发起授权 |

前置检查页面会直接告诉你本次上报的回调地址是什么，拿它去和后台登记的地址对照即可。

## 三、四个核算页面

### 1. 市场

搜物品中文名 → 看实时挂单。

- **实时买卖单**：左侧卖单升序、右侧买单降序，含单价/剩余/总量/地点
- **历史成交**：最近 398 天的每日均价、最低、最高、成交量、订单数
- **★ 收藏**：常查的物品加收藏，之后一键查

### 2. 工业

- 当前星系的**成本指数**（制造 / TE 研究 / ME 研究 / 拷贝 / 发明 / 反应）
- 各设施类型的实例数量

> **关于制造费的口径**（重要）：制造费**不是**按材料实际成本算，而是按
> **产物的估算市场价值 × 星系成本指数** 计入，再叠加设施基础费与设施税。
> 换星系会显著改变制造费。
>
> ESI 的设施接口只返回「设施实例 + 所属公司 ID」，**不含费率本身**
> （费率由各公司自定，需逐个查公司资料），所以本工具用成本指数口径。

### 3. 制造（蓝图画廊）

**搜产物名或类别**：

| 输入 | 结果 |
| --- | --- |
| `矮脚鸡级` | 名称精确匹配，1 个 |
| `护卫舰` | **类别匹配**，43 个（矮脚鸡级、秃鹫级、狮鹫级…） |
| `炮塔` | 类别匹配，56 个 |

> EVE 的舰船中文名是**船名**（矮脚鸡级）而不是类别词（护卫舰），
> 所以内置了**物品类别映射表**（`data/sde/item_categories.json`），
> 让常用的中文类别词也能搜到。

**核算流程**：

1. 搜到蓝图 → 点「核算」
2. 填 **ME**（材料效率等级）、**TE**（时间效率等级）、**流程数 runs**、**工业费**
3. 点「**拉取材料价**」自动填入单价与小计
   - 优先用本地 **EIV 基准价**（快，一次拿全量）
   - EIV 缺失时回退查市场卖单最低价
4. 填**产物卖价** → 自动出成本、利润、回报率、保本价

**关键口径**：

- ME 每级减 1% 材料量，**向上取整到下一位有效数字**（14.4 → 15）
- 制造时间 = 基础耗时 × TE 系数 × 工业理论系数 × 高级工业理论系数
- 投资回报率 = 利润 / 成本；毛利率 = 利润 / 毛收入（两个都显示，别混淆）
- 保本价 = 单件成本 ÷ (1 − 销售税 − 经纪费)

### 4. 挂单

独立于蓝图的**快速核算器**：

- 填单件成本、数量、目标回报率（%）、单流程耗时、卖价
- 直接得到：达到目标回报率/毛利率的最低卖价、保本价、净利润、回报率、毛利率
- **日产能**：每日流程数 = 86400 ÷ 单流程耗时 × 槽位；槽位取自你的技能

### 5. 提炼

矿石分级与精炼产出（含技能加成）：

- 35 个矿石族可选
- 每个级别列出精炼产物与数量
- 产出数量已计入「提炼学概论 +3%/级」与「提炼效率理论 +2%/级」的加成

## 四、税率口径（已按官方公式校正）

### ★ 三服税率不同

| 服务器 | 销售税基础 | 中介费基础 | 5 级技能后 |
| --- | --- | --- | --- |
| 欧服（宁静） | 7.5% | 3% | 销售税 3.375% / 中介费 1.5% |
| **国服 晨曦** | **8%** | **2.5%** | 销售税 **3.6%** / 中介费 1.0%（已达下限） |
| **国服 曙光** | **8%** | **2.5%** | 同晨曦 |

> ★ 国服数值来自 **2026-11-04 游戏内实测读数**（销售税 8%、中介费 2.5%），
> 并与国服 wiki「销售税约 3.6%–8%」交叉吻合：8% × (1 − 0.11×5) = 3.6%。
>
> 欧服的销售税基础值自版本 22.02（2025-03-12）起由 4% 上调至 **7.5%**。
>
> 旧项目「市场动态与制造核算台」用的是 `1.5% × (1−0.11×等级)` —— 基础值错了 5 倍，
> 导致挂单收益系统性偏高。该项目已修正（提交 `cc9c435`），本工具从一开始就是按官方口径。

### 中介费的完整公式

官方公式（CCP 支持中心《中介费和销售税》）：

```
中介费 = 基础 − 0.3% × 经纪人关系学等级 − 0.03% × 势力声望 − 0.02% × 军团声望
销售税 = 基础 × (1 − 0.11 × 会计学等级)
```

> ★ 工具此前**只算了技能项，声望两项从未读取**（配置表里配了系数但代码没用），
> 导致中介费系统性偏高最多 0.5 个百分点。现已补齐。

### 两项声望怎么填

两项声望都**相对于你挂单所在空间站的站主**：

| 项 | 含义 | 每点减免 | 满值（10 点） |
| --- | --- | --- | --- |
| **势力声望** | 与「站主所属势力」的声望 | −0.03% | −0.3% |
| **军团声望** | 与「站主军团」的声望 | −0.02% | −0.2% |

- 在「设置」页 → 「税率与声望（挂单相关）」里先**选挂单空间站**，
  工具会自动识别站主及其所属势力，并提示该查哪项声望。
- 声望取**原始值**（游戏内「角色 → 声望」），**不含**外交/关系学等技能加成。
- 负声望会**提高**费率。
- 玩家自建空间站的费率由业主设定，技能与声望都不适用。

### 若游戏内读数与工具不一致

「设置」页 → 「税率与声望」底部有**基础税率校准**输入框，
可直接填你游戏内看到的销售税/中介费基础值（百分数），工具立即按新值计算并存到本地。

## 六、常见问题

**Q：搜「护卫舰」找不到「矮脚鸡级」？**
A：现在能搜到了 —— 输入类别词会返回该类别下所有可制造物品。

**Q：拉取材料价很慢？**
A：正常情况走 EIV 本地缓存，秒级。若某物品 EIV 没有，会回退逐个查订单（较慢）。

**Q：提示「未能获取材料价格」？**
A：检查网络。若你在用 WorkBuddy 内置浏览器，它可能受网易 Cookie 干扰（国服 ESI 会误判登录态）—— **改用系统 Chrome/Edge**。

**Q：技能显示是 0 级？**
A：说明还没授权角色。授权后会自动同步；未授权时按 0 级技能算，仅作参考。

**Q：改了技能输入框，刷新后恢复了吗？**
A：是。手动改写只是临时推演，刷新即回到角色实际技能。

**Q：数据表显示「未加载」？**
A：正常 —— 只有用到该表的页面才会加载它。
