# EVE 辅助工具 —— 本地使用说明

> 面向个人日常使用：启动、授权、四个核算页面的用法与口径说明。

---

## 一、启动

```bash
cd "E:/工作/搞个程序/EVE/EVE辅助工具"
node server.js
```

打开 <http://localhost:8657>。

- 默认**单用户模式**：不校验口令，数据存在 `用户数据/users/local/`
- 默认**只监听 127.0.0.1**：局域网与公网都访问不到（个人使用更安全）
- 端口被占用会自动 +1 回退（上限 +20）

停止：终端按 `Ctrl+C`（会优雅关闭，等在途请求完成）。

---

## 二、首次使用：授权角色

**这是本工具与旧项目最大的不同** —— 技能不用手填。

1. 顶部右侧选服务器（晨曦 / 曙光 / 欧服）
2. 「角色」页点对应的「授权 XX 服」按钮
3. 浏览器跳转 EVE 官方登录页，登录并同意授权
   - 只申请 `esi-skills.read_skills.v1`（读取角色技能）一项权限
   - **不会**访问你的资产、钱包、行业任务
4. 授权后自动回调本地，同步技能并进入「角色」页

### 技能显示与微调

「角色」页列出 14 项技能，每项显示：

| 项 | 含义 |
| --- | --- |
| 名称与效果 | 如「会计学 · 市场销售税每级 −11%」 |
| Lv 徽章 | 当前等级（Lv5 为蓝色高亮） |
| 输入框 | 可临时改写，用于「假设我升到 V 级会怎样」的推演 |
| 进度条 | 等级比例 |

**手动改写的技能会标注「已手动覆盖」**，**刷新页面即恢复为角色实际技能** —— 不会污染真实数据。

下方「当前生效参数」实时汇总：销售税、经纪费、制造时间系数、制造槽、实验室槽、精炼加成。**这些值会直接代入挂单收益与制造核算。**

## 三、四个核算页面

### 1. 市场

搜物品中文名 → 看实时挂单。

- **实时买卖单**：左侧卖单升序、右侧买单降序，含单价/剩余/总量/地点
- **历史成交**：最近 398 天的每日均价、最低、最高、成交量、订单数
- **★ 收藏**：常查的物品加收藏，之后一键查

### 2. 工业

- 当前星系的**成本指数**（制造 / TE 研究 / ME 研究 / 拷贝 / 发明 / 反应）
- 各设施类型的实例数量

> **关于制造费的口径**（重要）：制造费**不是**按材料实际成本算，而是按
> **产物的估算市场价值 × 星系成本指数** 计入，再叠加设施基础费与设施税。
> 换星系会显著改变制造费。
>
> ESI 的设施接口只返回「设施实例 + 所属公司 ID」，**不含费率本身**
> （费率由各公司自定，需逐个查公司资料），所以本工具用成本指数口径。

### 3. 制造（蓝图画廊）

**搜产物名或类别**：

| 输入 | 结果 |
| --- | --- |
| `矮脚鸡级` | 名称精确匹配，1 个 |
| `护卫舰` | **类别匹配**，43 个（矮脚鸡级、秃鹫级、狮鹫级…） |
| `炮塔` | 类别匹配，56 个 |

> EVE 的舰船中文名是**船名**（矮脚鸡级）而不是类别词（护卫舰），
> 所以内置了**物品类别映射表**（`data/sde/item_categories.json`），
> 让常用的中文类别词也能搜到。

**核算流程**：

1. 搜到蓝图 → 点「核算」
2. 填 **ME**（材料效率等级）、**TE**（时间效率等级）、**流程数 runs**、**工业费**
3. 点「**拉取材料价**」自动填入单价与小计
   - 优先用本地 **EIV 基准价**（快，一次拿全量）
   - EIV 缺失时回退查市场卖单最低价
4. 填**产物卖价** → 自动出成本、利润、回报率、保本价

**关键口径**：

- ME 每级减 1% 材料量，**向上取整到下一位有效数字**（14.4 → 15）
- 制造时间 = 基础耗时 × TE 系数 × 工业理论系数 × 高级工业理论系数
- 投资回报率 = 利润 / 成本；毛利率 = 利润 / 毛收入（两个都显示，别混淆）
- 保本价 = 单件成本 ÷ (1 − 销售税 − 经纪费)

### 4. 挂单

独立于蓝图的**快速核算器**：

- 填单件成本、数量、目标回报率（%）、单流程耗时、卖价
- 直接得到：达到目标回报率/毛利率的最低卖价、保本价、净利润、回报率、毛利率
- **日产能**：每日流程数 = 86400 ÷ 单流程耗时 × 槽位；槽位取自你的技能

### 5. 提炼

矿石分级与精炼产出（含技能加成）：

- 35 个矿石族可选
- 每个级别列出精炼产物与数量
- 产出数量已计入「提炼学概论 +3%/级」与「提炼效率理论 +2%/级」的加成

## 四、税率口径（已按官方公式校正）

| 项 | 公式 | 5 级技能 |
| --- | --- | --- |
| 市场销售税 | `7.5% × (1 − 0.11 × 会计学等级)` | **3.375%**（官方 3.37%） |
| 经纪费（NPC 站） | `3% − 0.3% × 经纪人关系学等级`（下限 1%） | **1.50%** |
| 经纪费（玩家建筑） | 由建筑业主设定，**技能不影响** | — |

> 销售税基础值自版本 22.02（2025-03-12）起由 4% 上调至 **7.5%**。
>
> 旧项目「市场动态与制造核算台」用的是 `1.5% × (1−0.11×等级)` —— 基础值错了 5 倍，
> 导致挂单收益系统性偏高。该项目已修正（提交 `cc9c435`），本工具从一开始就是按官方口径。

## 五、数据来源与内置数据库

| 用途 | 来源 | 更新方式 |
| --- | --- | --- |
| 蓝图 / 工业活动 / 宇宙数据 | SDE（官方静态数据） | 构建脚本 |
| 物品中文名 / 空间站 / 矿石分级 | 官方每日包 evedata.xlsx | 构建脚本 |
| 技能效果 / 税率 | 人工维护（游戏机制常量，不在 SDE 中） | 随版本核对 |
| EIV 基准价 | ESI `/markets/prices/` | 自动缓存（国服 11834 条 / 欧服 16064 条） |
| 星系成本指数 | ESI `/industry/systems/` | 自动缓存（5485 星系） |
| 设施分布 | ESI `/industry/facilities/` | 自动缓存 |
| 实时挂单 / 历史成交 | ESI `/markets/*/orders/` `/history/` | 实时 |

数据表共 **17 张**，清单见「设置」页。

## 六、常见问题

**Q：搜「护卫舰」找不到「矮脚鸡级」？**
A：现在能搜到了 —— 输入类别词会返回该类别下所有可制造物品。

**Q：拉取材料价很慢？**
A：正常情况走 EIV 本地缓存，秒级。若某物品 EIV 没有，会回退逐个查订单（较慢）。

**Q：提示「未能获取材料价格」？**
A：检查网络。若你在用 WorkBuddy 内置浏览器，它可能受网易 Cookie 干扰（国服 ESI 会误判登录态）—— **改用系统 Chrome/Edge**。

**Q：技能显示是 0 级？**
A：说明还没授权角色。授权后会自动同步；未授权时按 0 级技能算，仅作参考。

**Q：改了技能输入框，刷新后恢复了吗？**
A：是。手动改写只是临时推演，刷新即回到角色实际技能。

**Q：数据表显示「未加载」？**
A：正常 —— 只有用到该表的页面才会加载它。
