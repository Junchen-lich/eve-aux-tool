# 术语对照表 · EVE Aux Tool Glossary

> **口径**：英文名称采用**欧服宁静（Tranquility）官方名称**，中文名称采用**国服（晨曦 / 曙光）译名**。
> 项目文档、界面文案与公式说明统一按本表书写。
> 技能名的机器可读单一来源为 [`data/sde/skills_zh.json`](../data/sde/skills_zh.json)（国服官方技能库 + 官方英文名，typeID 均已核验）。
> 市场税费的中文译名依据 CCP 官方中文支持中心《中介费和销售税》，英文依据其英文版《Broker Fee and Sales Tax》。

**译名要点**

- 「提炼学概论 / 提炼效率理论」中文沿用国服译名，英文按欧服宁静现名 **Reprocessing / Reprocessing Efficiency**；SDE 旧名 Refining / Refining Efficiency 仅供兼容旧数据。
- 「海关操作专业理论」对应 **Customs Code Expertise**，作用于海关办公室（Customs Office）的行星工业进出口税。
- 「科学原理」（Science）、「研究概论」（Research）、「冶金学」（Metallurgy）是三个不同技能，分别作用于蓝图拷贝、蓝图研究时间、材料效率研究速度。
- 国服未实装的技能不列入本表；工具界面按 `skills_zh.json` 渲染，以该文件为准。

## 六、书写约定

1. 文档正文中的技能名与游戏名词，**首次出现**写作「中文（English）」，例如「会计学（Accounting）」「反应（Reaction）」；后文可用中文简称。
2. 公式代码块内保持中文简称以保证可读性，紧邻的表格或说明给出双语对照。
3. 缩写（SDE / ESI / SSO / ME / TE / EIV / POCO / SCC / PI）首次出现给全称。
4. 三服数据在工具内完全隔离；引用服务器时同时给出中文名与英文键名。
5. 新增术语或游戏版本改名时，先更新 `data/sde/skills_zh.json`（技能）与本表，再改文档，避免多处不一致。
