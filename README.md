# EVE 辅助工具 · EVE Aux Tool

> 把游戏里的真实角色状态拉下来，自动代入官方工业公式，实时算出「做一单赚不赚、每天能做多少」。

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)
![Node.js](https://img.shields.io/badge/Node.js-%3E%3D18-green)
![第三方依赖](https://img.shields.io/badge/%E7%AC%AC%E4%B8%89%E6%96%B9%E4%BE%9D%E8%B5%BC-0-brightgreen)

面向 **EVE Online** 玩家的本地优先工具：角色数据同步、技能参数代入、市场与工业收益核算。
同时支持 **欧服（宁静）**、**国服经典服（晨曦）**、**国服曙光服** 三套独立的数据源与 SSO。

本项目独立于「市场动态与制造核算台」，自有代码与数据表。

---

## 快速开始

**环境要求**：Node.js **18 或更高**。零第三方依赖，下载即用，无需 `npm install`。

| 平台 | 操作 |
| --- | --- |
| Windows | 双击 `EVE辅助工具.cmd` |
| macOS / Linux / WSL | 终端执行 `./EVE辅助工具.sh` |
| 任意平台（手动） | `node server.js`，然后打开 <http://localhost:8657> |

一键脚本会进入交互菜单：启动（前台/后台）、停止、重启、查看状态、打开界面、查看日志、运行自检。
也可以直接下命令：

```bash
node scripts/launch.js start          # 前台启动，Ctrl+C 停止
node scripts/launch.js bg             # 后台启动
node scripts/launch.js status         # 查看运行状态
node scripts/launch.js stop           # 停止
node scripts/launch.js test           # 运行离线自检
node scripts/launch.js start --port 8660 --no-browser
```

默认只监听 `127.0.0.1:8657`；端口被占用时自动顺延（最多 +20），实际端口会写入 `用户数据/server.port`。
服务就绪后脚本才拉起浏览器。

## 首次使用

1. 打开页面后，先用**页面顶部的三服按钮**选择服务器（晨曦 / 曙光 / 欧服）。所选服会记住，三服数据互不混用。
2. 到「设置」页填写该服的 **Client ID**（在对应开发者后台注册应用，回调地址填 `http://localhost:8657/sso/callback`）。
   也可以用「角色」页的**手动授权**通道，无需注册应用。
3. 完成授权后，技能、属性、钱包、资产会自动拉取并保存在本地。
4. 未授权也能用：所有核算页按 0 级技能计算，可手动改技能等级做推演。

> 三套集群的应用互不通用，**每个服要单独注册 Client ID**。

完整步骤见 [用户手册](docs/用户手册.md)。

## 核心特性

- **三服原生支持**：各自独立的 ESI 入口、SSO 集群与市场补充数据源；切服自动清缓存、重绘当前页、隔离角色档案
- **角色数据自动同步**：官方 ESI 授权后拉取技能、属性、钱包、资产、工业任务并本地存档
- **技能参数自动代入**：14 项技能 → 税率、制造时间、槽位、提炼产出、研究速度五类系数
- **公式对齐官方**：销售税 `基础 × (1 − 0.11×会计学)`；中介费 `基础 − 0.3%×经纪人关系学 − 0.03%×势力声望 − 0.02%×军团声望`（下限 1%）
- **税率按服区分**：欧服 7.5% / 3%，国服晨曦与曙光 8% / 2.5%；支持在设置页按游戏内读数校准
- **挂单空间站与声望**：搜索并选定挂单空间站，自动识别站主及所属势力，填入两项声望后实时预览费率
- **内置完整数据表**：16 张静态表随仓库提供（蓝图、物品中英文名、空间站、矿石、税率等）
- **零第三方依赖**：仅 Node.js 内置模块 + 原生 HTML/CSS/JS

## 目录结构

本仓库**只包含运行必需文件、离线自检与说明文档**；数据构建脚本、联网测试、接口调研资料、开发过程记录与服务器部署配置均不随仓库发布。

```
├─ EVE辅助工具.cmd / .sh    一键入口（Windows / Unix）
├─ index.html               单页界面
├─ server.js                本地服务：静态托管 + SSO + ESI 代理 + 业务接口
├─ package.json             元信息与脚本（无依赖）
├─ LICENSE / NOTICE         GNU GPL v3.0 全文 / 版权与第三方声明
├─ scripts/
│  └─ launch.js             启动器：菜单 / 端口探测 / 健康检查 / 进程管理
├─ src/core/                三服配置、ESI 客户端、PKCE 授权、角色档案、
│                           技能映射、计算内核、空间站解析、用户存储
├─ src/data/                静态库加载、名称解析、ESI 数据拉取与缓存
├─ src/ui/                  界面逻辑、样式、浏览器端计算层、服务器切换
├─ src/**/*.test.js         10 个离线自检文件
├─ data/sde/                16 张内置数据表（JSON）
├─ docs/                    用户手册、本地使用说明、计算公式参考
└─ .env.example             服务端环境变量模板
```

运行期产生的 `用户数据/`（角色档案、令牌、日志、端口记录）已在 `.gitignore` 中排除，**不会被提交**。

## 三服数据源

| 服务器 | 官方 ESI | SSO | 市场补充 |
| --- | --- | --- | --- |
| 欧服（宁静） | `esi.evetech.net/latest` | `login.eveonline.com` | ceve `/tqapi`、c3q `eve.c3q.cc` |
| 国服 晨曦 | `ali-esi.evepc.163.com/latest` | `login.evepc.163.com` | ceve `/api`、c3q `cn.c3q.cc:20080/eve/market/api/` |
| 国服 曙光 | 同上（ESI 不区分服） | 同上 | c3q `cn.c3q.cc:20080/eve/market-sg/api/`、ceve `/infapi` |

> 国服 `typeID` 体系与欧服不同，技能映射等按服独立维护，不可混用。

## 隐私与数据

- 所有角色数据只保存在本机 `用户数据/`，不上传任何第三方服务器
- 多用户模式下 EVE 令牌以 **AES-256-GCM** 加密落盘
- 公开数据（市场订单、成本指数等）按需从官方 ESI 拉取并本地缓存
